# tcp-video-lab-student
# Forking & Cloning: Share the link to tcp-video-lab-student repository 
# 1. logs into your own GitHub account and clicks the Fork button in the top-right corner of your repository page. 
# 2. clones your personal fork to your local machine:
Bash
git clone https://github.com/student-username/tcp-video-lab-student.git
cd tcp-video-lab
# Student Development & Local Workflow
# 1. complete the required logic inside client.py and server.py to replace the TODO comments.
# 3. commit your changes locally:
Bash
git add client.py server.py 
git commit -m "Complete TCP socket TODOs and performance evaluation"
# 4. push the completed work back to your personal fork on GitHub:
Bash
git push origin main
# Submission via Pull Request
# 1. When ready to submit, navigate to your personal fork on GitHub.
# 2. click the Pull Requests tab and click New Pull Request.
# 3. click Create Pull Request, adding your name and student ID in the title or description (e.g., Submission by person - ID 12345 "stud mat").
